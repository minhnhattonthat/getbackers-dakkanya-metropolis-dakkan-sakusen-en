# Style reference

Approved voice for every translator and reviewer. Pilot: the Act 1 opening (scenes 7927E4-792E54), translated by
the controller. A box holds 2 lines of 216 px (~40-45 characters each); the tools wrap the text.

## Corrected example
- 7927E4.22: first draft "Ginji, we're the invincible GetBackers (dakkanya)." - the （だっかんや） is a furigana
  reading gloss for the kanji, not something to translate: drop it.
- 792CFC.17: first draft "What'd you say, punk?! Oh, we've got business, all right! Feel the wrath of a stolen
  meal!!" did not fit 2x216 px; trimmed filler ("punk", "Oh,") rather than meaning.
